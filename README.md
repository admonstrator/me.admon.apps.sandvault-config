# Sandvault Config

A native macOS companion for [sandvault](https://github.com/webcoyote/sandvault): overview, control and
fine-grained permissions for the `sandvault-$USER` sandbox account.

`sv` keeps installing the sandbox and starting sessions. Sandvault Config adds what is missing around it:

- live view of sandbox processes, sessions and network connections
- a per-user firewall with a domain-aware proxy and allow/deny prompts
- sandbox rule editing with a learn mode fed by sandbox violations
- quick hand-off of a repository to an agent inside the sandbox

Status: under construction. See `docs/PLAN.md`.
